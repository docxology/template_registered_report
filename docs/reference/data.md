# Registration fixtures

- [example_registration.json](../../data/example_registration.json) records
  hypothesis H1, its primary outcome, the analysis plan, and review metadata.
- [claim_ledger.yaml](../../data/claim_ledger.yaml) maps exemplar claims to
  the registration and generated evidence.

Freeze the registration before executing the analysis. The
[review artifacts](../rendering.md#regenerate-the-evidence) record any
departures from the plan.
