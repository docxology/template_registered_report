# manuscript - template_registered_report

Registered-report manuscript for the exemplar. Sections render in filename order:

- [`00_abstract.md`](00_abstract.md) — template scope and the bound headline numbers.
- [`01_introduction.md`](01_introduction.md) — why the lock-validate-execute-compare ordering matters.
- [`02_hypotheses.md`](02_hypotheses.md) — preregistered hypothesis H1 and the registered outcome
  (embeds `fig:hypothesis_map`).
- [`03_methods.md`](03_methods.md) — frozen registration, analysis plan, and deterministic
  demonstration data (embeds `fig:analysis_dag`).
- [`04_results.md`](04_results.md) — confirmatory outcome bound to `output/data/demo_analysis.json`
  (embeds `fig:permutation_result`) and the registered sensitivity-analysis row
  bound to the frozen registration's `sensitivity_analyses`.
- [`05_deviations.md`](05_deviations.md) — deviation register and severity classification (embeds
  `fig:deviation_timeline`).
- [`06_discussion.md`](06_discussion.md) — scope, limitations, and fork guidance.
- [`99_references.md`](99_references.md) — bibliography generated from the works cited in the report.

Pandoc uses [references.bib](references.bib) and [preamble.md](preamble.md).
See the [rendering guide](../rendering.md) for the pinned runner.

Figures live in [`figures/`](figures/README.md) and are regenerated by
`scripts/generate_figures.py`. Configuration is in
[`config.yaml`](config.yaml); forkable defaults in
[`config.yaml.example`](config.yaml.example). Every reported number is derived
from executed code — do not hand-edit statistics into the prose.
